◉ An end-to-end Generative AI application that empowers business users to interact with relational databases in plain English. The agent autonomously introspects the database schema, writes safe SQL, handles execution errors, and synthesizes final insights.

◉ This project demonstrates a production-ready enterprise AI workflow: Tool Calling → Schema Introspection → Query Generation → Human-in-the-Loop (HITL) Approval → Data Visualization.

---

◉ **Business Context**
<p style="margin-top:1rem;"></p>

While static dashboards are great for tracking high-level KPIs, business leaders constantly need answers to ad-hoc, granular questions (e.g., "What was the revenue drop in the West region last quarter?"). Fulfilling these requests manually creates massive bottlenecks for data analysts.

LLMs offer a conversational interface to data, but standard text-to-SQL models are risky: they hallucinate table names, write invalid syntax, or execute dangerous queries. 

This project solves that operational bottleneck by implementing an **Agentic Workflow**. Instead of just generating text, the LLM is equipped with restricted database tools and a cyclical reasoning process, ensuring it grounds its queries in reality and requires human authorization before touching the database.

---

◉ **What I Built**
<p style="margin-top:1rem;"></p>

- **LangGraph State Machine (The Brain)**
  - Engineered a cyclic graph architecture routing the LLM between "reasoning" and "acting."
  - Implemented `MemorySaver` checkpointer to maintain conversational history and handle follow-up queries.

- **Custom Tool Ecosystem (The Hands)**
  - `list_tables`: Scans metadata to discover available datasets.
  - `get_schema`: Injects exact column names and data types into the LLM context to prevent hallucinations.
  - `execute_query`: A restricted `SELECT`-only execution environment.
  - `generate_chart`: A Python sandbox where the LLM writes Matplotlib code to visualize its SQL results.

- **Human-in-the-Loop (HITL) Security**
  - Configured LangGraph breakpoints to freeze the execution state right before the `execute_query` node.
  - Forces a human approval step where the drafted SQL is audited before execution, guaranteeing zero unauthorized data access.

- **Streamlit Analytics Terminal**
  - Built a clean, enterprise-grade UI featuring system audit logs, real-time tool execution tracking, automated chart rendering, and one-click CSV data exports.

◉ **Key Capabilities**
<p style="margin-top:1rem;"></p>

- **Schema-Grounded Generation:** The agent never guesses column names; it explores the live database schema first.
- **Self-Correction Loop:** If PostgreSQL throws a syntax error, the agent reads the traceback and autonomously rewrites the query.
- **Multi-Turn Memory:** Users can ask contextual follow-ups (e.g., "Now filter that chart to only show refunded orders").
- **Dynamic File Export:** SQL execution results are instantly converted into downloadable CSVs via Pandas.
